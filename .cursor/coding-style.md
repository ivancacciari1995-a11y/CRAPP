# Coding Style

Preferenze del progetto.

- Utilizzare TypeScript.
- Preferire funzioni piccole.
- Evitare duplicazione di codice.
- Utilizzare componenti React riutilizzabili.
- Commentare solamente il codice realmente complesso.
- Preferire nomi descrittivi.
- Non introdurre librerie senza reale necessità.
- Mantenere la struttura esistente del progetto.
